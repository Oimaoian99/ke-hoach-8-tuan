Đồng bộ tiến độ qua GitHub

Lưu tiến độ vào một ghi chú bí mật (Gist) trên GitHub của bạn. Mở trang ở máy nào cũng thấy cùng tiến độ.

  1. Bấm tạo token GitHub (đăng nhập GitHub nếu được hỏi). Ô gist đã được tích sẵn.
  2. Ở mục Expiration chọn 90 days hoặc No expiration, kéo xuống cuối bấm Generate token.
  3. Sao chép mã bắt đầu bằng ghp_, dán vào ô dưới rồi bấm Kết nối.
  4. Làm lại bước 3 trên mỗi máy (điện thoại, máy tính) với cùng một token.

Token chỉ có quyền đọc/ghi Gist, không đụng được vào code hay repo. Token lưu trong trình duyệt của máy này, không gửi đi đâu ngoài GitHub.
